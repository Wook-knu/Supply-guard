# SupplyGuard SGRI 산출 방법론

> 공급망 리스크 지수(**SGRI**, Supply-chain Global Risk Index)의 설계 원칙,
> 6개 지표의 데이터 출처·산출식, 가중치 결정 방식, 재현성과 한계를 정리한 문서.
> (심사 대응: "지수 산출의 전문성·객관성" 근거 자료)

---

## 1. 설계 철학 — "지표는 공식, 가중치는 AI + 검증"

SGRI는 **역할을 이원화**한다.

| 구성 | 담당 | 이유 |
|---|---|---|
| **6개 지표 점수** | 결정적 **공식/통계**(SQL·Python) | LLM은 산술에 부정확·비재현적. 지표는 공개데이터 + 표준 통계량으로 계산해야 **재현 가능·검증 가능** |
| **6개 지표의 가중치** | **LLM(Gemini) + Python 검증** | 품목마다 어떤 위험이 더 중요한지는 맥락 판단 → LLM이 데이터를 보고 제안, 단 **기준값 대비 범위 제한**으로 통제 |

이 분리가 핵심 경쟁력이다. **"AI가 점수를 지어낸다"는 블랙박스가 아니라, 점수는 누구나 재현 가능한 공식으로 계산하고, AI는 가중치 조정에만 제한적으로 쓰며 그 근거를 저장**한다.

## 2. 데이터 출처 (전부 공개·무료 API)

| 지표 | 데이터 출처 | 접근 |
|---|---|---|
| S 수급 불안정성 | UN Comtrade (국가별 수입액 시계열) | 공개 API |
| C 공급처 집중도 | UN Comtrade (공급국별 수입 비중) | 공개 API |
| V 가격 변동성 | FRED 원자재 종합가격지수(PALLFNFINDEXM) + 한국은행 ECOS 환율(731Y001) | 공개 API |
| L 물류 리스크 | IMF PortWatch(항만 물동량) + GDACS(글로벌 재난경보) | 공개 API |
| P 국가·정책 리스크 | World Bank WGI(세계 거버넌스 지표 6종) | 공개 API |
| E ESG·탄소규제 | EU CBAM 배출 기본값 / 전과정평가(LCI) 배출계수 | 공개 자료 |

> 공개·무료 데이터만 사용 → **비용 없이 투명하게 재현 가능**. 상용 데이터 구매 없이도 동작한다는 점이 차별점.

## 3. 6개 지표 산출식

모든 지표는 **0(안전)~100(위험)** 으로 정규화된다.

### S — 수급 불안정성 (Supply instability)
공급국이 시간에 따라 얼마나 들쭉날쭉 공급하는지 = **수입액 시계열의 변동계수(CV)**.

```
CV = σ(수입액) / μ(수입액)          # 국가×품목, 연도별 (2019~2023)
score_S = 100 × (CV − CV_min) / (CV_max − CV_min)   # 품목 내 국가 간 min-max
```
- 근거: CV는 규모에 무관한 표준 변동성 지표. 다년 데이터(≥2기간) 있는 국가만 산출.

### C — 공급처 집중도 (Concentration)
소수 국가에 의존할수록 위험 → **허핀달-허쉬만 지수(HHI)**.

```
HHI = Σ sᵢ²          # sᵢ = 공급국 i의 수입 비중(0~1)
score_C = HHI × 100
```
- 예: 한 나라서 100% 수입 → HHI=1.0(=100점) / 10개국 균등 → HHI=0.1(=10점).
- 근거: HHI는 공정거래·산업조직론에서 표준으로 쓰이는 집중도 지표.

### V — 가격 변동성 (Volatility)
원자재 가격과 환율의 최근 24개월 변동성.

```
CV_fred = σ/μ (FRED 원자재지수, 24개월)
CV_fx   = σ/μ (ECOS 원/달러 환율, 24개월)
score_V = min(100, 평균(100·CV_fred, 100·CV_fx))
```
- 근거: 가격·환율 각각의 CV를 100배 스케일 후 평균. 데이터 있는 쪽만 사용.

### L — 물류 리스크 (Logistics)
항만 물동량 안정성 + 재난 리스크.

```
port_score  = winsorized_minmax(항만 기항 CV, p10~p90)   # IMF PortWatch, 국가별
disaster    = Σ(재난경보 심각도: Red 3/Orange 2/Green 1)  # GDACS, 최근 6개월
disaster_score = 100 × disaster / max(disaster)
score_L = 0.6·port_score + 0.4·disaster_score           # 둘 다 있을 때, 하나면 그 값
```
- 근거: 항만 물동량의 변동성(CV)은 물류 처리 불안정을 반영. 아웃라이어 왜곡을 막기 위해 p10~p90 윈저화 정규화.

### P — 국가·정책 리스크 (Policy)
World Bank 세계거버넌스지표(WGI) 6종 평균을 위험으로 반전.

```
avg_gov = mean(표현·책임성, 정치안정, 정부효과성, 규제품질, 법치, 부패통제)  # 각 −2.5~2.5
score_P = clamp₀₁₀₀( (2.5 − avg_gov) / 5 × 100 )
```
- 근거: 거버넌스가 좋을수록(estimate 高) 정책·제도 위험 낮음 → 선형 반전.

### E — ESG·탄소규제 리스크 (ESG/carbon)
탄소 배출집약도가 클수록 CBAM 등 탄소규제 부담 高.

```
total_emission = 직접배출 + 간접배출          # EU CBAM 기본값(HS6별), 없으면 LCI 배출계수
score_E = 100 × (E − E_min) / (E_max − E_min)  # 품목 간 min-max
```
- 근거: EU CBAM은 탄소집약 품목에 실제 관세를 부과 → 배출집약도가 곧 규제 리스크.
- **한계 고지**: CBAM 비대상 품목(예: 리튬)은 공개 LCA 문헌 기반 LCI 참고값을 사용하며, 정식 배출계수 확보 시 교체한다(4장 참고).

## 4. 가중치 결정 — Gemini 제안 + Python 검증

### 4.1 기준 가중치 (baseline)
전문가 사전(prior)으로 설정한 기본 비중.

```
BASE = { S:0.25, P:0.20, V:0.15, L:0.15, C:0.15, E:0.10 }   # 합 = 1.0
```

### 4.2 LLM 제안
Gemini에 **각 지표의 실제 점수·근거**(품목의 6지표 값)를 입력하고 가중치를 제안받는다.
- LLM 역할은 **가중치 제안에 한정**. 프롬프트에서 "최종 SGRI 점수는 계산하지 말라"고 명시.
- 예: 리튬은 집중도(C)가 73점으로 최고 → Gemini가 C 비중을 0.15→0.23으로 상향, 근거(rationale) 함께 반환.

### 4.3 검증 (통제 장치)
LLM 출력을 그대로 쓰지 않고 두 단계로 통제한다.

1. **정규화**: 제안 가중치를 합=1로 정규화(음수·비정상 제거).
2. **기준값 범위 제한(projection)**: 각 가중치를 **기준값 ±0.08 이내**로 클리핑 후 재정규화.
   → LLM이 특정 지표를 극단적으로 왜곡하지 못하게 막는다.
3. **폴백**: LLM 실패/응답 이상 시 규칙 기반(신뢰도 반영) 또는 기준 가중치로 자동 대체.

이 검증 덕분에 **가중치는 항상 전문가 기준값 근방에 머물며, 근거가 저장(재현 가능)** 된다.

## 5. 최종 SGRI 합성

```
SGRI = Σ(scoreᵢ × wᵢ) / Σ(wᵢ)     # 값이 있는 지표만으로 정규화 가중합
```
- 결측 지표는 분모에서도 제외 → 데이터 없는 지표가 점수를 왜곡하지 않음.
- 위험 등급: **SGRI ≥ 50 높음 / ≥ 25 중간 / < 25 낮음**.
- 결과와 함께 **가중치·근거(weights_json)** 를 저장 → 대시보드·리스크 상세·AI 보고서가 **동일한 값**을 사용(일관성 보장).

---

## 6. 재현성·투명성

- **결정적 계산**: 동일 입력 → 동일 6지표 점수(SQL·통계량). 난수·LLM 산술 없음.
- **근거 저장**: 가중치 rationale, 가중치 프로파일(weights_json), 추천 근거가 DB에 남는다.
- **공개 데이터**: 모든 소스가 공개 API → 제3자 검증 가능.
- **일관성**: 화면·보고서가 같은 DB 값을 참조(별도 계산 없음).

## 7. 한계와 정직한 고지

| 지표 | 한계 | 대응 |
|---|---|---|
| E ESG | 일부 품목은 정식 배출계수 대신 LCA 참고값 사용 | 참고값임을 라벨링, 정식 LCI 확보 시 교체 |
| S 수급 | 다년 무역데이터 있는 국가만 산출 | 데이터 없는 국가는 결측 처리(가중합에서 제외) |
| L 물류 | 항만 물동량 변동성은 물류 리스크의 프록시 | GDACS 재난과 결합, 향후 운임·리드타임 데이터 추가 |

→ **모르는 것을 지어내지 않고 결측·프록시임을 명시**하는 것이 신뢰의 근거다.

## 8. 심사 피드백 대응 요약

- **"엠로 등 기존 솔루션과 차별점"** — 엠로는 사내 구매/SRM 중심(폐쇄형·고비용). SupplyGuard는 **공개데이터 기반·투명한 산출식·실시간 SaaS**로, 상용 데이터 구매 없이 중소 수출기업이 바로 쓸 수 있다.
- **"컨설팅과 차별점"** — 컨설팅은 1회성·수작업·고가. 본 서비스는 **자동화·실시간·구독형**으로 상시 모니터링과 조기경보를 제공한다.
- **"예측 정확도"** — 본 서비스는 미래를 단정하는 블랙박스 예측이 아니라, **설명 가능한 지표 기반 조기경보**다. 각 점수의 근거와 데이터 출처를 제시한다.
- **"ESG(E) 근거 부족"** — E는 CBAM/LCI 기반으로 산출하되 **한계를 투명하게 라벨링**하고, 지표를 모듈화해 정식 데이터 확보 시 즉시 교체 가능한 구조다.
